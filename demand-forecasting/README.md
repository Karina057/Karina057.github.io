# Demand Forecasting Analysis

**Type:** Self-directed Supply Chain practice project  
**Tools:** Excel, moving-average forecasting

## Goal
Use historical monthly demand to create a simple forecast that could support inventory and replenishment planning.

## What I did
- Organized 12 months of synthetic demand data.
- Built a 3-month moving-average forecast.
- Compared forecasted demand with actual demand.
- Calculated forecast error using MAE and MAPE.
- Produced a forecast for the next month.

## Key results
- Next-month forecast: **612 units**
- Mean Absolute Error (MAE): **38.7 units**
- MAPE: **7.0%**

## Takeaway
A moving-average model provides a simple baseline for demand planning. Forecast accuracy can be evaluated before using a forecast to support inventory decisions.

> **Note:** The dataset is synthetic and was created for portfolio practice; it does not represent a real company.
